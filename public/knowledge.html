ЩО ТАКЕ ОПЕРАЦІЙНА СИСТЕМА

Операційна система (ОС) — це системне програмне забезпечення, яке керує апаратними ресурсами комп’ютера та надає програмам і користувачеві єдиний спосіб працювати з ними. Без ОС кожна програма мусила б сама вміти працювати з процесором, памʼяттю, дисками й екраном.

Керування процесамиРозподіляє час процесора між запущеними програмами (планування).
Керування памʼяттюВиділяє кожній програмі власний простір і використовує диск як розширення RAM.
Файлові системиОрганізовує дані на дисках у файли й папки з правами доступу.
Драйвери пристроївПриховує від програм відмінності між різним обладнанням.
БезпекаРозмежовує користувачів і програми, захищає дані.
ІнтерфейсНадає графічну оболонку та командний рядок для роботи людини.

ЩО ТАКЕ WINDOWS

Windows — родина власницьких (проприєтарних) операційних систем корпорації Microsoft. Назва походить від англійського «вікна»: головною особливістю була графічна оболонка з вікнами. Перша версія, Windows 1.0, вийшла 1985 року як графічна надбудова над MS-DOS.

Історично є дві лінії системи. Перша, на основі MS-DOS, охоплює Windows 1.0–3.x та Windows 95, 98 і Me. Друга, лінія NT (New Technology), почалась із Windows NT 3.1 1993 року: це повністю нова 32-бітна система з захищеною памʼяттю та правами доступу. Windows XP обʼєднала лінії на основі ядра NT, і всі сучасні версії, від Windows 2000 до Windows 11 та Windows Server, належать до лінії NT.

Крім настільної системи існують серверні редакції (Windows Server), системи для вбудованих пристроїв і мобільних платформ (Windows CE, Windows Phone), а також хмарні й віртуалізаційні технології.

АРХІТЕКТУРА WINDOWS NT

Лінія NT має шари з різним рівнем привілеїв. Програми працюють у режимі користувача і не можуть напряму зачепити обладнання, а головні компоненти системи — у режимі ядра.
